# Github Actions

## Intro

Allows claude code to directly modify code in Github. Eg, you can create an issue and it will create code to fix it.

You can create an Github issue" and tag @claude in the comment to ask it to implement it. It will provide a fix in a brnach and this will be deployed in Vercel so you can see if it is fixed. If so merge the PR.

## Install 
type /install-github-app and follow the prompts. You need to install github cli and add claude code app to github repo. To this it will create a PR which we need to merge to main
