# Open Source

You can use open source model with claude code. but the quality is not that great but it is free. It also takes huge amount of HDD as you will download the model say 900MB with qwen3. It also needs a powerful computer.

Download ollama
associate a model to ollama 
    ollama pul. qwen3
Launch claude from ollama
    ollama launch claude

Expand context window in settings. This will require high GPU
